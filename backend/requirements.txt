# ===========================
# OCR (Sprint 12.5)
# ===========================
# Decodes embedded/standalone raster images (PNG/JPEG, and the images
# pypdf extracts from a scanned PDF page) before handing them to
# Tesseract. Already present transitively (via reportlab); pinned
# directly since this sprint imports it in production code, not just
# test fixtures.
Pillow==12.3.0
# Thin wrapper around the `tesseract` CLI binary -- no ML framework in
# the Python process itself. Chosen over EasyOCR/PaddleOCR (each pulls
# in PyTorch/PaddlePaddle, multi-GB, GPU-oriented) and over PyMuPDF-based
# rasterization (AGPL-3.0/commercial dual license -- a real risk for a
# project that may become closed-source SaaS, versus Tesseract's
# Apache-2.0). Requires the `tesseract-ocr` system package (see
# Dockerfile) -- ~19MB installed, Apache-2.0, fully offline, no API key,
# no per-call cost. See extractors.py/ocr.py for the integration.
pytesseract==0.3.13
