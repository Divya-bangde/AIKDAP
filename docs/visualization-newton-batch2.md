# Newton — Batch 2 frontend implementation

16 October 2026. Batch 1 review gate was approved before these changes. Root owns V09 contrast/styling and Experiment visualization integration, and browser screenshots/checks; Nicolas owns canonical schemas. No Batch 3 renderer/theme work is included here.

## Changes and verified findings

- **V07:** the existing research/analytics views lacked a common chart-level context/table/export shell. `ChartFrame.tsx` now supplies a title; deterministic per-series displayed-value ranges/counts rather than unverified narrative; axis titles/declared units; origin; source controls; filter/time/scope qualifications; actual selected-trace values; paginated access to all values; contextual JSON download and a reported download failure. Table extraction covers XY, null gaps, pie labels/values and rectangular grid coordinates, including Plotly's numeric default grid indexes. The figure associates its context and detailed alternative. Source exports retain real citation/asset/chunk/reference/URL identifiers when provided. Research exports include run/project/question/intent/provenance; analytics exports retain analysis/dataset/computation/scope/numeric-encoding metadata. Unknown fields are labelled honestly.
- **V07/V09 integration:** every multi-trace frame offers series checkboxes. The exact selection drives renderer, findings, values and export; full received traces remain accessible separately. UID or a unique trace name preserves selection across reorder; anonymous/duplicate-name legacy traces use an explicit positional fallback. Root disables independent Plotly legend toggles, preventing table/export from silently disagreeing with hidden marks.
- **V07 equations:** both equation card variants use the same frame with computed sampling origin, current evaluated result, expression/input metadata and exact current/reference/compare traces. No evaluator allowlist, reference snapshots, or stable/widen-only axis behavior was removed. Root's Experiment wrapper uses the same API.
- **V09 review correction:** equation reference and comparison curves now retain full opacity to preserve essential contrast. The reference remains dotted; five comparison samples use deterministic distinct dash patterns. Current/reference width and marker distinctions remain. Root owns the associated contrast/browser and mock-opacity regression evidence.
- **V08:** `PaperMap.tsx` now has a searchable production HTML paper list for every node, including isolated/no-edge papers. Keyboard selection opens the same Radix sheet/source/import controls as canvas clicks. Escape/close restores the connected opener or search input. Fit/reset/zoom/pause/resume controls act on the real graph. Node-size/global-citation meaning and arrow direction are explicit; list filtering does not silently filter the graph. Tests never invoke a real import.
- **V11:** slider names use the variable's meaningful name and symbol, `aria-valuetext` reports physical values and spoken known units (for example `1 kilogram; logarithmic scale`), and numeric inputs remain synchronized. Log/linear scale semantics are visible and announced. Nonfinite values and nonpositive values for originally logarithmic domains are rejected with an alert while preserving the valid state. Both single/system cards are covered; root updated the equation regressions.
- **V12:** `MermaidDiagram.tsx` preserves natural SVG width inside a labelled, keyboard-focusable local scroll region and exposes zoom/reset controls; labels are not automatically shrunk to phone width. Full relationship source remains a text alternative in the frame. Mermaid strict mode is retained. `ResearchRunView.tsx` uses a concise visual-task title and expandable full question. `ResearchResult.tsx` places visual status/origin/scope/finding/chart before lengthy answer text. Source access and full explanation remain available. Long labels wrap; slider rows can reflow.

## Browser controls for root's gate

- Chart frame: **Select series (N of N)**, checkbox labels match trace names, **Inspect plotted values**, **Previous values / Next values**, **Inspect all received series**, **Download plotted data and context**.
- Paper map: **Search papers by title or year**, **Inspect paper: {title}**, **Fit paper map**, **Reset paper map view**, **Zoom in paper map**, **Zoom out paper map**, **Pause paper map animation / Resume paper map animation**. Sheet **Open paper**, **Add to project** (inspect only), **Close**.
- Diagram: **Zoom in diagram**, **Zoom out diagram**, **Reset diagram view**, **Scrollable diagram**, **Diagram relationships (text alternative)**.
- Equation: slider accessible name **{physical name} ({symbol})**; numeric name **{physical name} ({symbol}) value**. Physical `aria-valuetext` includes units and scale.
- Research: **Full research question** disclosure; requested visualization appears before explanation.

Real browser graphical fidelity, actual accessibility-tree behavior, touch/200% zoom and contextual browser download artifacts remain root's acceptance gate; component tests do not establish those claims. Detailed renderer recovery, live equation theme, image/SVG exports and performance optimization remain Batch 3.
